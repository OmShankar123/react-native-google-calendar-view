# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-31

### Added

- Initial release of react-native-google-calendar-view
- Day, Week, and Month view modes
- Customizable event rendering
- Smart overlapping event layout
- Multi-day event support
- Custom theming system
- Event legend with color coding
- Interactive event selection and expansion
- Auto-scrolling to events
- Smooth animations with React Native Reanimated
- TypeScript support with comprehensive type definitions
- Flexible header layouts (row/column)
- Configurable legend position (left/right)
- Custom event markers
- Custom time slots
- Configurable start hour
- Event press callbacks
- Date change callbacks
- View mode change callbacks
- Responsive design with screen size adaptation
- Horizontal scrolling for wide week views
- Comprehensive example app
- Full documentation

### Features

- **Three View Modes**: Switch between Day, Week, and Month views
- **Event Management**: Add, display, and interact with calendar events
- **Customization**: Extensive theming and styling options
- **Smart Layout**: Intelligent handling of overlapping events
- **Performance**: Optimized rendering with memoization
- **Accessibility**: Semantic component structure

### Developer Experience

- Full TypeScript support
- Comprehensive prop interfaces
- Sensible defaults
- Extensible event model
- Clean API design
